# Support

Use [GitHub Issues](https://github.com/NoxelS/openpatch/issues) for reproducible bugs and feature requests. Include the OpenPatch version, VS Code version, operating system, configured endpoint family (without credentials), and steps to reproduce.

Questions about a particular model provider, account, billing, retained data, or outage belong with that provider. OpenPatch is a local extension and does not operate an AI endpoint or process user documents itself.

For security-sensitive reports, follow [SECURITY.md](SECURITY.md) rather than opening a public issue.
